The essentials — questions about QAid.

What is QAid?

QAid is a free Chrome extension that brings 20 manual-testing tools into one side panel: bug report with video, form autofill and audit, JWT, Base64, URL and JSON decoders, environment emulation, an element inspector and a defect scan. The panel opens over any tab — no need to switch to DevTools or third-party services.

How much does QAid cost?

QAid is completely free. There are no paid plans, subscriptions, trial periods or limits — all 20 tools are available right after install.

Do I need an account or sign-up?

No. QAid works with no sign-up, no login and no account — install it and start using it right away.

Is QAid safe and what data does it collect?

QAid collects no data. All tools run locally, in your browser: the extension makes not a single network request and uses no cloud, analytics or trackers. You can verify this yourself in the Network tab of DevTools.

What tools are included in QAid?

20 tools: bug report, annotated screenshot, screen recording, form autofill, form audit, decoders (JWT, Base64, URL, JSON), device, language, geolocation and timezone emulation, element inspector, defect scan, WCAG contrast check, ruler, page colors and fonts, state comparison, text and style overrides, cookies and storage, login profiles, generators for time, hashes, UUIDs, numbers and strings, and network request mocking.

Which browsers does QAid work in?

QAid works in Google Chrome and in Chromium-based browsers — Microsoft Edge, Brave, Opera, Vivaldi, Arc and Yandex Browser.

How is QAid different from DevTools?

DevTools is a developer console, while QAid is a panel for the tester. QAid handles the routine of manual QA: it produces a ready bug report with video and technical details, fills forms with test data, overrides the environment and decodes tokens — all things that take many manual steps in DevTools.

How do I install QAid?

Open the QAid page in the Chrome Web Store and click “Add to Chrome”. No sign-up needed — the side panel appears right after install.
